# HashMeme

HashMeme is a simple social media feed app dedicated to sharing and exploring memes. Users can upload, browse, and interact with memes in a seamless experience.

## Features
- 📷 **Upload Memes** – Share your favorite memes with the community.
- 🔄 **Infinite Scrolling** – Enjoy an endless feed of memes.
- 💾 **AWS S3 Storage** – Secure and scalable image hosting.
- 🔐 **OAuth Authentication** – Easy login with Google.
- ⚡ **Optimized Performance** – Efficient caching and pagination for smooth browsing.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Tanstack Query
- **Backend:** Express.js, MongoDB
- **Storage:** AWS S3
- **Authentication:** Google OAuth 2.0, JWT
